# iraqi-currency-rates
IRAQI CURRENCY RATES – منصة متكاملة لعرض أسعار صرف العملات في العراق، تشمل أسعار الدولار والعملات الأجنبية حسب المحافظات، مع تحديثات مباشرة ورسوم بيانية وتنبيهات ذكية ولوحة تحكم إدارية لإدارة الأسعار والعملات والمستخدمين والإشعارات. يدعم التطبيق اللغة العربية ويهدف إلى توفير معلومات دقيقة وسهلة للمستخدمين.
